# 🤝 Code of Conduct

## Our pledge
We want Cyber Hub to be a friendly, welcoming project for everyone, whatever their experience, background, gender, religion, nationality or level of skill.

## Expected behaviour
- Be kind and patient, especially with beginners.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the people who use Cyber Hub to stay safe.

## Not acceptable
- Harassment, insults, or personal or political attacks.
- Publishing anyone's private information.
- Using the project, its issues or its discussions to share malware, exploits against real people, or stolen data.

## Enforcement
The maintainer may remove comments, code or contributors that break these rules. Report problems to the maintainer through GitHub: [@Syed-Muhammad-Tayyab](https://github.com/Syed-Muhammad-Tayyab).

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
